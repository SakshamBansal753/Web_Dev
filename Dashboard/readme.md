# 📊 Data Dashboards Repository

This repository contains a collection of **interactive dashboards** built using **Power BI** and **Microsoft Excel**.  
The dashboards are designed for data analysis, reporting, and visualization across different datasets and use cases.

---
# 📊 Dashboards Overview
🔹 Power BI Dashboards

- Interactive reports with slicers and drill-downs

- Clean data models and calculated measures

- Optimized for business insights and decision-making

🔹 Excel Dashboards

- Dynamic dashboards using formulas and pivot tables

- Automated calculations and visual summaries

- User-friendly layouts for quick analysis
